Install guide — Windows

FLOATING v0.2.0, VST3 format, Windows x64.

This is a beta build — not signed, not yet through a full installer. That’s expected, not a mistake on your end.

Install

  1. Extract FLOATING-Windows-latest-beta.zip (right-click → Extract All, or your usual tool).

  2. Copy the FLOATING.vst3 folder to:

    C:\Program Files\Common Files\VST3\

    If that folder doesn’t exist, create it first. Writing here needs administrator permission (Windows will prompt via UAC) — that’s normal for this location, not specific to FLOATING.

    Prefer not to deal with admin rights? You can instead use the per-user path, no elevation needed:

    %LOCALAPPDATA%\Programs\Common\VST3\

About the security prompt you won’t see

Unlike some other platforms, Windows doesn’t require VST3 plugins to be signed, and SmartScreen only gates programs you launch directly — a plugin loaded by your DAW isn’t launched the same way, so there’s no “unblock” step to hunt for here. The only prompt you may see is the standard UAC permission request from writing into Program Files, which is about the folder, not about FLOATING itself.

Confirm it’s installed

Open your DAW, force a plugin rescan if it doesn’t appear automatically, and look for FLOATING under VST3 instruments/effects (check your DAW’s own scan log if it doesn’t show up).

New in this build

The Capture recovery gesture now works on Windows: Ctrl-click Capture to step back to the previous Memory. It was unreachable on Windows in the previous beta.

Keyboard navigation works on Windows: Tab moves through the panel and the arrow keys change values. Confirmed by hand in Ableton on this build.

Known issues on this beta

The version in the plug-in reads v0.1.0

The Windows build shows v0.1.0 in its footer. This is the correct current build — only the version label inside it is out of date. Nothing to report.

Uninstall

Delete the FLOATING.vst3 folder from wherever you installed it. There’s no separate uninstaller for this beta.
